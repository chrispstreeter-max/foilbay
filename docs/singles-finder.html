Singles finder

The collection page is built for finding one card fast.

Turn on filters

  1. Install Shopify Search & Discovery (free, made by Shopify).
  2. Open the app › Filters › Add filter.
  3. Add Availability, Price, Rarity and Condition (category fields or the Condition variant option), plus Tag if you use set: tags, and Vendor if each game is a vendor.
  4. Rename filters as you like. The names appear in the sidebar.

Filters update the results instantly, without reloading the page. On phones, they open in a drawer.

Quick filter chips

Singles finder › Quick filter chips shows one filter as a row of chips above the results, for example Rarity or Set. Type the filter's name exactly as it appears in the sidebar.

Grid and list view

Shoppers can switch between a binder grid and a dense list view that shows set, number, rarity, price and condition chips on one line. Their choice is remembered. Set the starting view in Singles finder › Default view; List suits stores where most customers search for specific cards.

Settings

Setting What it does
Show filters Sidebar on desktop, drawer on phones
Columns on desktop 3–6 cards per row in grid view
Products per page 12–48
Show collection image / description Header above the finder

Theme settings › Product cards controls what every tile shows: card image shape (trading card 63:88, square or natural), foil shine, set and number, rarity, condition chips and the game (vendor).
