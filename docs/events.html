Events and tournaments

Use the Events section on your home page (next few events) and on an Events page (the full calendar).

Create the events page

  1. Online Store › Pages › Add page, title it Events.
  2. Set Template to page.events.
  3. In the theme editor, open the page and add an Event block for each event.

Event blocks

Setting Notes
Date YYYY-MM-DD, for example 2026-11-14
End date For events over several days
Start / end time 24-hour, for example 18:30
Game and format Shown as chips; the game also powers the filter chips
Entry fee Shown as written, such as $10 or Free
Ticket product Sell entry as a product. Its inventory shows "spots left" and the button adds a ticket to the cart.
Registration link For events you manage elsewhere

Past events hide automatically the day after their date (turn off Hide past events to keep them). Shoppers can add any event to their calendar, and Foilbay publishes each event to Google as structured data.

Selling tickets

Create a product per event (for example Prerelease Weekend Entry), set its inventory to the number of seats and choose it as the block's Ticket product. When it sells out the event shows Event full.
