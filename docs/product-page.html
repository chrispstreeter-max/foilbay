Product page

The product page adapts to what you're selling.

Singles: the condition table

When a product has a Condition (or Grade) option, the Condition table block lists every variant as a row with condition, other options (such as finish), stock, price, a quantity stepper and Add. Sold-out rows can stay visible so shoppers know the condition exists.

Link a page explaining your grading in Condition table › Condition guide page.

Sealed product and accessories

Products without a condition option use the Variant picker and Buy buttons blocks instead (option pills, quantity, add to cart and dynamic checkout). Tag sealed product preorder to sell it before release.

Graded slabs

Set the category field Grading (PSA, BGS, CGC…) and Foilbay shows a grade badge next to the set and rarity. Use the product title for the grade, for example Voltmane · PSA 10.

Blocks
